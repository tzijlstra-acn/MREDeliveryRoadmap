    Architecture and Application Onboarding

    On-premises architecture, orchestration boundaries and application integration

    Seven-layer on-premises architecture with deterministic workflow ownership and bounded agent execution. Four application integration tiers, defaulting to the lowest tier sufficient for reliable evidence.

    Obligation Chain and Run View

    From external obligation to DDCR-reported conformance status

    Three run patterns: regulatory change (Run A), application impact and remediation (Run B), and continuous evidence and monitoring (Run C). Every step shows its execution mechanism. Human gates are non-negotiable. MITRA and MAYA are provisionally assigned agent names.
